# 📞 Interfon — внутренний телефон для связи с вашим ИИ-агентом

[Español](../../README.md) · [English](README.en.md) · [中文](README.zh.md) · [Português](README.pt.md) · [한국어](README.ko.md) · **Русский** · [日本語](README.ja.md) · [Français](README.fr.md)

**Interfon** превращает ваш ПК и Android-телефон в голосовой внутренний телефон: агент может
**позвонить вам**, **поговорить с вами** и **прислать аудиосообщения**; вы можете позвонить ему
или пользоваться режимом **рации**. Всё работает **локально** (в вашей сети WiFi) через ваш
собственный API для инференса (Unsloth Studio), без сторонних сервисов.

```
   ┌───────────────────────── ПК (Windows) ─────────────────────────┐
   │                                                                │
   │  Агент (CLI) ──┐                                               │
   │                ▼                                               │
   │  ┌──────────────────────────┐    ┌───────────────────────────┐  │
   │  │  Сервер Interfon         │    │  Unsloth Studio API       │  │
   │  │  (FastAPI + WebSocket)   │───▶│  http://127.0.0.1:8888    │  │
   │  │  :8765                   │    │  · LLM  gemma-4-E2B       │  │
   │  │  · VAD / STT / TTS       │    │  · STT  qwen3-asr-0.6b    │  │
   │  │  · голос Piper (Daniela) │    └───────────────────────────┘  │
   │  └───────────┬──────────────┘                                   │
   └──────────────┼──────────────────────────────────────────────────┘
                  │ WebSocket (JSON + аудио), локальный WiFi — один или несколько ПК
                  ▼
   ┌───────────────────────── Android ──────────────────────────────┐
   │  Приложение Interfon (Compose, тёмная тема)                    │
   │  · Принимает звонки (звонит поверх экрана блокировки)          │
   │  · Голосовой разговор с агентом (субтитры в реальном времени)  │
   │  · Рация: удерживайте, чтобы говорить                          │
   │  · Получает аудио агента, даже когда приложение закрыто        │
   └─────────────────────────────────────────────────────────────────┘
```

## Возможности

| Возможность | Как работает |
| --- | --- |
| 📲 Входящие звонки | Агент запускает `call_user.py` → телефон **звонит** (на весь экран, вибрация, мелодия) → вы отвечаете и разговариваете. |
| 📞 Исходящие звонки | Кнопка «Позвонить агенту» в приложении → мгновенный голосовой разговор. |
| 🎙️ Рация | Удерживайте кнопку, отпустите — сообщение отправится; агент отвечает голосом. |
| 📻 Push-аудио | `send_audio.py "текст"` → приложение воспроизводит аудио даже в фоне (при отсутствии связи — ставит в очередь). |
| 🔤 Речь в текст | `qwen3-asr-0.6b` через ваш локальный API (~1,6 с на фразу). |
| 🧠 Мозг | `gemma-4-E2B-it` (настраивается) с `enable_thinking:false` для коротких устных ответов. |
| 🗣️ Голос агента | **Piper `es_AR-daniela-high`**, запасной вариант — SAPI (Sabina es-MX). Другие голоса: `python scripts/download_voice.py --list`. |
| 🌓 Тёмная тема | Всегда включена, Material 3, зелёный на сине-чёрном. |
| ✍️ Расшифровка | Всё сказанное (обеими сторонами) отображается на экране и записывается в `server/logs/`. |
| 📡 Автопоиск | Приложение сканирует локальную сеть и само добавляет **все** найденные серверы (без настройки IP). |
| 🖧 Несколько серверов | Одновременное подключение к нескольким ПК. Любой из них может позвонить вам или прислать аудио; ваши звонки и рация идут через первый подключённый сервер в списке, а если он отключится, его заменит следующий (failover). У каждого сервера есть **своё имя**. |
| 📋 Сворачиваемый список | На главном экране карточка серверов сворачивается и показывает счётчик `подключено/всего`; в развёрнутом виде — состояние каждого. |
| 🌐 8 языков | Español, English, 中文, Português, 한국어, Русский, 日本語 и Français. Выбирается при первом запуске и меняется в **Настройки → Язык** (на Android 13+ также в *Настройки системы → Язык приложения*). |

## Начало работы

### 1. ПК: сервер

```powershell
cd Interfon
.\scripts\setup_server.ps1          # venv + зависимости + голос Piper (~114 МБ с HuggingFace)
# Необязательно (от администратора), чтобы принимать подключения телефона по WiFi:
.\scripts\setup_server.ps1 -Firewall

cd server
.\.venv\Scripts\python.exe serve.py
```

Требования: **Unsloth Studio** (или любой OpenAI-совместимый API), запущенный на `127.0.0.1:8888`
без пароля. Адрес и модели задаются в `server/.env`.

Это можно повторить на нескольких ПК: приложение подключается ко всем сразу.

### 2. Android: приложение

Установите APK из последнего [release](https://github.com/jhonsu01/interfon/releases)
(`Interfon-vX.Y.Z.apk`, подписан). При запуске:

1. Выберите язык (только в первый раз).
2. Разрешите доступ к микрофону и уведомлениям.
3. **Всё**: приложение само находит серверы (сканирует локальную сеть, проверяет `/api/status`
   и подключается ко всем). Если ни один не подключён, поиск повторяется автоматически.
   Можно запустить его и вручную кнопкой **🔎 Найти серверы в сети**.
4. Карточка **Серверы** показывает `подключено/всего`; нажмите на неё, чтобы свернуть или развернуть.

#### Несколько серверов

В **Настройки → Серверы** можно:

- **Добавить** сервер вручную (`192.168.1.50`, `192.168.1.50:8765` или полный URL).
- **Переименовать** его (например, «ПК в офисе», «Ноутбук») или изменить URL кнопкой ✏️.
- **Повысить приоритет** кнопкой ⬆️: первый подключённый сервер в списке обслуживает ваши исходящие
  звонки и рацию; если он отключится, приложение само перейдёт на следующий.
- **Удалить** его в том же окне редактирования.

Все серверы могут одновременно звонить вам и присылать аудио. Если вы разговариваете с одним, а
другой пытается позвонить, приложение отклонит вызов как «занято».

> По USB также работает `adb reverse tcp:8765 tcp:8765` с добавлением сервера
> `http://127.0.0.1:8765`.

### 3. Разговор

```bash
# на ПК (из папки server/):
./.venv/Scripts/python.exe call_user.py "Есть минутка?"                 # позвонить на телефон
./.venv/Scripts/python.exe send_audio.py "Сборка прошла успешно"        # push-аудио
./.venv/Scripts/python.exe send_audio.py "я устал" --reply              # ответ пишет LLM
./.venv/Scripts/python.exe status.py                                    # общее состояние
```

В приложении: **Позвонить агенту** — для разговора, **Рация** — для коротких обменов.

## 🤖 Руководство для ИИ-агентов (интеграция в сессию)

Любой агент с доступом к ПК может через Interfon **говорить с пользователем**: слышать, что тот
сказал голосом, отвечать аудио, звонить ему или присылать подкасты. Всё работает по HTTP через
`http://127.0.0.1:8765` (LAN, без аутентификации). В примерах
`$S` = `server/.venv/Scripts/python.exe`.

### Состояние системы (всегда проверять первым)

```bash
$S server/status.py        # или: curl http://127.0.0.1:8765/api/status
```

Ключевые поля: `phone_connected` (приложение на связи?), `llm.loaded`, `session.active`.

### Агент → человек: отправить голос

| Хочу | Вызов |
| --- | --- |
| Отправить аудио (эффект входящего звонка) | `POST /api/message` `{"text": "..."}` |
| Позвонить на телефон (звонит поверх блокировки) | `POST /api/call` `{"text": "повод"}` — произносится при ответе |
| Аудио с ответом, написанным локальной LLM | `POST /api/message` `{"text": "...", "reply": true}` |

```bash
$S server/send_audio.py "Сборка готова, всё зелёное"     # push-аудио
$S server/call_user.py "Есть минутка?"                   # звонок
```

### Человек → агент: услышать, что он сказал

Всё сказанное (звонок, рация) расшифровывается в `server/logs/transcripts-ГГГГ-ММ-ДД.jsonl`:

```json
{"ts": "2026-10-01T20:45:01", "kind": "stt", "ctx": "walkie", "text": "Какая оценка..."}
```

`kind`: `stt` (голос человека) · `agent` (устный ответ) · `message_pushed` · `telegram` · события
звонка. Чтобы продолжить разговор: `tail` файла за день и фильтр `kind=stt`. Затем ответьте через
`send_audio.py` — это и есть полный цикл «разговора по телефону из сессии агента».

### Спросить без отправки аудио

```bash
curl -X POST http://127.0.0.1:8765/api/ask -H "Content-Type: application/json" \
     -d '{"text": "погода в медельине"}'
# → {"reply": "В Медельине сейчас 20 градусов...", "grounded": true}
```

Те же навыки, что и у телефона: дата/время/состояние ПК, погода, новости, поиск в интернете и
Википедии, праздники Колумбии (остальное — LLM).

### Подкаст по статьям (papercast)

1. Выберите свежую статью с высоким рейтингом (arXiv/тренды) и перескажите её в 4–8
   **разговорных частях** (~700 символов каждая, простые аналогии, числа без изменений —
   в стиле «объясни как ребёнку»).
2. Сохраните части в `.txt`, разделяя их строками `---`.
3. Воспроизведите:

```bash
$S server/papercast.py script.txt   # каждая часть приходит как звонок, с паузами
```

### Telegram (необязательно)

`TELEGRAM_BOT_TOKEN` в `server/.env` (подхватывается на лету, без перезапуска). Пользователь
авторизует свой чат командой `/start`; бот отвечает с теми же навыками. Написать ему с ПК:
`$S server/telegram_send.py "текст"`.

### Правила работы

- **Полудуплекс**: не отправляйте аудио во время активного звонка (`session.active`).
- Задержки: STT ~1,6 с · локальная LLM 2–10 с (первая загрузка ~90 с) · TTS ~1–4 с.
- Длинное аудио: делите на части короче 900 символов (так удобнее слушать).
- Главный — сервер: после перезагрузки ПК `serve.py` нужно запустить снова.

## Измеренные задержки (Ryzen 5 3400G, встроенная графика)

| Шаг | Время |
| --- | --- |
| STT (фраза ~5 с) | ~1,6 с |
| LLM gemma-4-E2B (короткий ответ, прогретая) | ~2-10 с |
| TTS Piper daniela-high | ~1-4 с |
| **Итого на обмен** | **~5-15 с** (маленькая локальная модель: ожидаемая задержка) |

## Безопасность

- Всё работает **только в локальной сети**: данные агента не уходят в интернет (кроме загрузки
  голоса с HuggingFace).
- У сервера **нет аутентификации**: используйте его только в доверенной сети.
- Хранилище ключей для подписи и `.env` лежат в `.secrets/` и **никогда** не попадают в репозиторий.

## Структура

```
Interfon/
├── android/               # Приложение Kotlin + Compose (тёмная тема, адаптивные иконки, 8 языков)
├── server/                # FastAPI + WebSocket + провайдеры (Unsloth API, Piper, SAPI)
│   ├── interfon_server/   #   main (протокол), providers, vad, wavutil, state, config
│   ├── serve.py           #   запуск
│   ├── call_user.py       #   CLI: позвонить на телефон
│   ├── send_audio.py      #   CLI: отправить аудио
│   └── status.py          #   CLI: состояние
├── scripts/
│   ├── setup_server.ps1   #   подготовка ПК
│   ├── download_voice.py  #   голоса Piper с HuggingFace
│   └── publish_release.py #   повышение версии + сборка + release на GitHub
├── docs/arquitectura.md   # подробный протокол WebSocket
├── docs/i18n/             # этот README ещё на 7 языках
└── directives/            # регламент работы проекта
```

## Публикация новой версии

```bash
python scripts/publish_release.py patch   # или minor / major
```

Повышает `versionCode`, собирает подписанный APK, создаёт тег и публикует release на GitHub.
